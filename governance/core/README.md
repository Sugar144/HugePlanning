# Reusable Governance Core

This in-place L0–L2 boundary contains only candidate content approved by G6
B-01. `project-operating-contract.md` is the initial L0 core surface.

L1 and L2 mechanisms were deliberately not moved in B-02. B-05 adds only a
namespaced identity-allocation boundary: its namespace, state, ledger, and any
forward-only historical compatibility map remain project-owned configuration.
Historical records are not renamed or migrated.
The core contains no HugePlanning adopter binding, project values, L3 content,
or L5 evidence/history.

`configuration-schema.yaml` defines the explicit L1 configuration keys that a
project-owned adopter binding supplies when the core refers to an adopter value.
